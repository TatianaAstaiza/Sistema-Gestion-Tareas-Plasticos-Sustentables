# Sistema de Gestión de Tareas – Plásticos Sustentables

## 1. Descripción del proyecto

Sistema web desarrollado para la empresa Plásticos Sustentables, orientado a facilitar la gestión de tareas, usuarios y asignaciones de empleados.

El proyecto busca mejorar la organización de las actividades de la empresa, permitiendo administrar las tareas y realizar seguimiento a su estado.

## 2. Funcionalidades principales

- Registro e inicio de sesión de usuarios.
- Creación, consulta, edición y eliminación de tareas.
- Asignación de tareas a empleados.
- Búsqueda y filtrado de tareas.
- Control de tareas pendientes y completadas.
- Cambio de contraseña.
- Control de acceso y permisos de usuarios.

## 3. Tecnologías y herramientas utilizadas

- **Lenguaje de programación:** Python.
- **Framework:** Django.
- **Base de datos:** PostgreSQL.
- **ORM:** Django ORM.
- **Entorno de desarrollo:** Visual Studio Code.
- **Control de versiones:** Git y GitHub.
- **Pruebas automatizadas:** Django Test Framework.
- **Cobertura de código:** Coverage.py.

## 4. Ejecución del proyecto

Para iniciar el servidor de desarrollo, ejecutar desde la terminal del proyecto:

```bash
python manage.py runserver
```

Después, abrir en el navegador:

`http://127.0.0.1:8000/`

Se realizaron pruebas manuales y automatizadas para verificar el funcionamiento del sistema.

**Pruebas manuales:**

**Pruebas automatizadas:**
